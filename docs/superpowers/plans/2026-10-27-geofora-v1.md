# GEOFORA v1 — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Objetivo:** globo 3D clicable con mapa de calor de noticias y un panel por país con ficha básica, noticias (multilingües, titulares traducidos), música y cultura, desplegado en el VPS.

**Arquitectura:** backend FastAPI que precarga noticias de GDELT con una tarea programada y sirve música y cultura bajo demanda con caché en SQLite; los datos básicos son un JSON estático generado una vez. El frontend React + `react-globe.gl` solo consume `/api/*`. Nginx sirve el frontend y hace de proxy al backend.

**Stack:** Python 3.12, FastAPI, httpx, APScheduler, SQLite (`sqlite3` de la stdlib), pytest + respx · Node 20, React 18, Vite, react-router, react-globe.gl, Vitest + Testing Library · Nginx, systemd, Let's Encrypt.

**Spec:** `docs/superpowers/specs/2026-10-27-geofora-design.md`

## Restricciones globales

- Interfaz en **español**. Las URLs de país son `/pais/{slug}` con el nombre en español, minúsculas, sin tildes y con guiones (`afganistan`, `costa-de-marfil`).
- Ninguna clave de API llega al navegador: `LASTFM_API_KEY` y `DEEPL_API_KEY` solo existen como variables de entorno del backend.
- Todo dato externo mostrado lleva **fuente y fecha**.
- Ningún apartado se muestra vacío: siempre hay un respaldo o un mensaje honesto.
- Noticias en cualquier idioma; solo se traducen los **titulares**, bajo demanda, cacheados para siempre por hash; los que están en español no se traducen; si la traducción falla, se muestra el original con su idioma.
- TTLs: noticias, ciclo de 30–60 min (por defecto `NEWS_INTERVAL_MIN=45`); música 5 días; cultura 21 días.
- GDELT: como mucho 1 petición cada 5 s.
- MusicBrainz: como mucho 1 petición/s, con `User-Agent: GEOFORA/1.0 (ajulianrague@gmail.com)`.
- Si una fuente falla, se sirve la caché caducada indicando su fecha.
- Geometría: Natural Earth 1:110m, sin editar fronteras ni nombres.
- No se aloja audio ni artículos: solo previews de Deezer, titulares y enlaces.

## Foco de revisión

1. **País sin noticias** (GDELT devuelve 0 artículos, p. ej. Tuvalu): `/news` responde `200` con `articles: []` y la UI muestra "No hay noticias recientes de este país". → test en la Tarea 5 y en la Tarea 10.
2. **Una fuente externa cae o da timeout** con caché caducada disponible: se sirve la caché con `stale: true` y su `fetched_at`. → test en la Tarea 3 (cache) y la Tarea 7 (música).
3. **Slug desconocido o con tildes** (`/pais/afganistán`, `/pais/narnia`): el slug se normaliza; si no existe, la API da `404` y la UI muestra "País no encontrado" con el buscador. → test en la Tarea 2 y la Tarea 10.
4. **Cuota de DeepL agotada** (HTTP 456) o error: los titulares salen en su idioma original con `translated: false`, sin error 500. → test en la Tarea 6.
5. **Polígonos de Natural Earth sin código ISO** (`ISO_A3 = -99`: Kosovo, Somalilandia, Chipre del Norte): el script usa `ADM0_A3` como respaldo; si no hay ficha, el país sigue siendo clicable y el panel muestra solo el nombre. → test en la Tarea 2.
